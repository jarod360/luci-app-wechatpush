## 3.6.20

新增 TP-LINK 无线客户端辅助检测，默认关闭，支持 QWRT 原生及原 fork 检测两种模式。

- 无线断开满 30 秒且新的成功采集仍确认离线后，直接进入推送，不再等待原检测超时。
- 接入、漫游成功或当前在线会取消离线；异常、过期和未知状态暂缓判断。
- 有线设备及未启用辅助时保留原检测；原推送过滤、免打扰、合并及失败重试保留。
- 绿色数量按钮可查看设备、IP、MAC、AP、SSID；手机只显示名称、IP、AP，优先使用 WeChatPush 别名。
- 后台串行轮询与增量日志查询，页面只读缓存，不额外登录 TP-LINK。
- 修复 QWRT 下中文/流量模板偶发乱码、别名特殊字符，以及残留 ARP 撤销离线判定的问题。
- 企业微信通道说明更新，图文日志标记为“【企业微信图文版】”。

已在 TL-R5005P-AC 1.0 / 固件 1.0.4 Build 260414、QWRT 25.12.2 上验证；其他型号与固件需确认接口兼容性。
安装主包及对应中文语言包，启用服务后，在基础设置填写 TP-LINK 管理地址和账号并保存应用。

完整说明与判定规则见 [README](https://github.com/jarod360/luci-app-wechatpush#readme)。
IPK/APK 由不同 OpenWrt SDK 构建，请选择与你的包管理器匹配的产物。
